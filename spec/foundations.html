The tokens that hold everything together.

Tokens are the smallest, shareable unit of design. Use these — not raw hex values, not magic px numbers — and the rest of the system rebuilds itself when something changes.

01 · Color

Color roles, not raw colors

Every color in Twiglit has a job. Don't reach for the hex — reach for the role. The token moves; the hex doesn't.

Surface layers

The desktop chrome is four stacked greys, each darker than the last. Read them top-down: who, where, what, selected. The body is pure white because everything else is grey.

Brand

One bright green for actions and logo, one deep green for text on grey, one soft tint for selected/hover states. Everything else that used to be green has been retired.

Green #417505 · --green
Green deep #2d5103 · --green-deep
Green soft #e8f0da · --green-soft

Roles. --green = brand bg (logo, primary buttons, FAB, leaf-soft bar). --green-deep = green text on grey (action-bar verbs, "+ New twigl" link, focused folder). --green-soft = green tint behind selected items, callouts.

Berry & Ink

Berry #b86b6a · --berry
Berry soft #f1dcdb · --berry-soft
Ink #40404a · --ink

Berry is the bullet color and the avatar fallback. Ink is the right-side rail and the mobile pill — never use either for body backgrounds.

The palette is closed. No new greens. No new greys. If you need a new role, propose adding it as a token rather than reaching for a fresh hex — that's how a system stays a system.

02 · Typography

System stack, four weights

We rely on the system stack — -apple-system first. No webfonts. Four weights are available: regular (400) and bold (600) cover the default rhythm; medium (500) and heavy (700) are available when bold doesn't give enough nuance.

Hero56 · 600 · -0.022em Grow softly.
Display40 · 600 Trees, not folders.
Page title28 · 600 Weekly planning
Section20 · 600 Today's twigs
Heading17 · 600 A node is the atom
Lead17 · 400 · 1.6 A twig is a node. The berry is the bullet. Leaves are how you view it.
Paragraph15 · 400 · 1.5 The reading size for prose — design system docs, modal copy, settings. Stops growing at 17.
Body / row14 · 400 · 1.5 The default size in the tree, in lists, in nav. Tight enough to fit information, loose enough to read at glance.
Small12 · 400 Secondary labels, supportive text, breadcrumb crumbs at small sizes.
Micro11 · 400 Timestamps. Badge text. The smallest you ever go.
Mono11 · SF Mono ⌘ K · ⌥ ↵ · ⇧ ⌘ T — keyboard shortcuts only

04 · Radii

Square. Always.

Twiglit doesn't soften its corners. The product reads as ink on paper — a notebook, not an interface. Two exceptions exist for one reason each.

default · 0px
--berry · 50% The bullet is the brand. It stays round.
pill · 999px Filter chips only. Earned, not default.

If you find yourself wanting to round something: ask whether it's actually the berry or a filter chip. If not, square it.

05 · Motion

Sub-100ms or refactor

Twiglit targets <100ms on everything. If a transition takes longer than that, something is wrong with the code, not the design.

--d-fast80msHover, focus, taps, color swaps — default for everything
--d-base100msCeiling — panel slide, accordion open
--easecubic-bezier(0.2, 0.7, 0.2, 1)The only easing

Patience is calm; slowness is rude. If you find yourself wanting a longer easing, the answer is almost always to remove the animation entirely.

06 · Iconography

Traditional, simple, hairline

Cleanly drawn, traditional metaphors — a house is a house, a magnifier is a magnifier. 1.5–1.75px stroke, rounded line caps and joins. Square optical bounds.

This set is a placeholder. The target is a custom set drawn for Twiglit. Until then we use a single traditional style (Phosphor regular, or hand-redrawn equivalents).
